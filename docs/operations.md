# Governed maintenance pipeline
Run `node src/portfolio.mjs repoops.example.json` for a read-only portfolio report. Explicit `--apply` permits issue publication only for repositories configured with write-enabled modes and appropriate credentials. Use a narrowly scoped GitHub App installation token. Do not expose tokens to model calls or untrusted repository execution.

The README remediation API is intentionally limited to a missing conventional README and deterministic content, with a linked open issue and fresh base SHA. It is not wired to unattended execution. AI proposals are untrusted text; no coding-agent shell or autonomous patch application is enabled. Release signals are configured upstream releases, not a comprehensive GitHub trending feed. The merge gate is a pure predicate, not a live merger; a trusted review identity and check attestation integration are still required. Feedback is an append-only local event log, not an autonomous policy editor. Portfolio output is JSON, not a hosted dashboard.

Operational prerequisites: enforce repository rulesets and required checks; use separate read and write identities; verify GitHub App permissions; test on a disposable repository before enabling writes. Serialize write runs; after network ambiguity, inspect GitHub before retrying. Do not automatically delete branches containing unmerged commits. No deployments or secrets changes.
