DEVELOPER GUIDE

Start maintaining.

Run RepoOps locally with Node.js 22 or later. Start in read-only mode.

InstallationAuditSchedulingPortfolioSafety

Installation

git clone https://github.com/AnkitParekh007/repoOps.git
cd repoOps
npm test

Run an audit

npm run audit -- owner/repo

Reports include the inspected commit SHA and conventional community-file findings. For private repositories, use a scoped read-only token via GITHUB_TOKEN.

Scheduled audits

A daily GitHub Actions workflow checks elapsed time since the last successful audit. Audit artifacts retain checkpoints for 30 days.

Scheduling reference ↗

Portfolio configuration

node src/portfolio.mjs repoops.example.json

The example uses observe mode. Explicit apply and repository policy are needed for issue publication. Do not enable writes without a scoped credential and disposable-repository validation.

Operations reference ↗

Safety and limitations

No general coding sandbox or live automatic merger is available yet. Do not give AI proposals access to secrets or execute untrusted repository instructions.
